# Helper mod-tier how-tos

Only the MOD knowledge pack gets these (the helper reads it only when the asker has role 3 or higher). Short, practical, no secrets and no tokens. One `## Title` section per entry.

## Change the private match name
!lobbyname NAME sets the private match name. Customs use a name only: the bots never save or say a password. The helper and !pm both read the new name at once.

## Strikes
!strike @user gives a temporary strike, !strike @user perma adds a permanent one (add a reason such as toxicity, slurs, racist or hate). !unstrike @user removes one and !unstrike @user perma removes a permanent one. Temporary strikes fade by one per full day.

## Teach the bots
Mods and trusted viewers use !teach with a short fact, or !correct to fix a wrong one. Ivan approves each note before the bots use it.

## Review what the helper missed
Each night the helper writes the questions it could not answer into the nightly notes so the knowledge pack can learn them. Tell Ivan about repeated wrong answers.

## Asked to change the stream title
The helper cannot change the title. A mod can change it with !title <new title>.

## A message is held by AutoMod or a clip will not go through
The helper cannot release it. A mod can approve a held message in the Twitch mod view. For a Twitch clip link held by AutoMod, ask a mod.

## A chatter is calling the streamer slurs
Stay calm and do not reply to them: time them out or ban them, add a permanent strike with !strike @user perma slurs, and report the account to Twitch if it is bad. Tell Ivan if it keeps happening.

## Asked to do something only a mod can do (ban, mod, unmod, settings)
The helper cannot ban, time out, mod, unmod or change settings. Point the person to a mod, one short thankful line.

## Add a command or send an idea
Mods can send an idea with !teach <text> and Penguin approves it. The helper cannot add commands itself.

## Where is the wheel
The tournament wheel is mod only. Viewers who ask about it should be pointed to a mod.

## Mark a game incomplete
Mods can mark a game as incomplete when it did not finish normally.

## Show or reload the helper pack
!helperpack shows how many entries the helper knows (public and mod). !helperpack reload loads the newest knowledge files right away instead of waiting for the next refresh.
