# Nightly checklist (runs when Ivan says we are done for the night)

Owner: 00 (coordinator). Engine work routed through 02 (PenguinHost) and its forks; site/FAQ through 05.

## 1. Learn from the day's chat logs (every night)
- Read the day's chat logs (Data\ recorder jsonl, Chatty jsonl, helper review log) for:
  - **Feedback**: viewers and mods saying what they liked, disliked or asked for.
  - **Mistakes**: wrong, missed, doubled or unwanted bot replies; moderation misfires; commands that failed; answers corrected by mods or Ivan.
  - **Experience**: what worked well (jokes that landed, questions Helper answered cleanly).
- **Learn new commands**: any command typed in chat that no bot answers, mod-created commands, new in-jokes. Propose them as lore/commands (Ivan's Teach inbox rules apply: nothing public is changed without approval, except mod-added commands, which go live right away).
- Write a short summary to Docs\nightly\YYYY-MM-DD.md (what we learned, what we changed, what needs Ivan).

## 2. Engine code audit (3 passes, fix issues) and per-engine reports (updates, capabilities, future plans)
## 3. Docs refresh: Ivan (advanced + friendly), 00 (super advanced, internal), mods (simple, website + chatbot), viewers (simple, FAQ + chatbot). Public docs/chatbot never explain internals.
## 4. Housekeeping: APP_LOG.md entries current, profiles/commands re-pushed, site batch pushed, memory notes updated.
