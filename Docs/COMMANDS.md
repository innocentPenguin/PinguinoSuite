
- `!me` (everyone; join the tournament wheel while sign-ups are open; 3 strikes = refused). `!wheel ...` (mods; see CHANGES.md). Both must exist as Streamer.bot commands.
- `!games` / `!game` (everyone; answered by ChattyPinguino, canned entry `games`): lists what can be played in chat: `!gamble`, `!slots`, `!duel`, `!give` (only the ones switched on in `Data\economy\gambling.json`) and Guess the Chatter, which is started through `!shop`. Cooldown and duplicate guard apply. The list text comes from the `$(games)` variable (also usable in the canned editor).
- `!shop` (everyone; Host, one reply): lists what is for sale (items and prices from `site_shop_settings.json`: `ShopOpen`, `ChatItems`, stake range, cooldowns). `!shop guess <stake>` starts Guess the Chatter: the stake is taken with a unique id ("you have no points" / "not enough points" / cooldown / a round already running are answered once), the Host shows an old anonymised chat line and the player answers with `!guess <name>` (3 tries, 5 min); a right answer pays 2x. Items marked `enabled:false` show as coming soon.
- `!gamble`, `!slots`, `!duel`/`!accept`/`!decline`, `!give` (Host engine; the result line is spoken by ChattyPinguino through a `PgGame` event when Chatty can post, otherwise the plain Host line. Exactly one of the two, never both). Slots reels are real emoji.
